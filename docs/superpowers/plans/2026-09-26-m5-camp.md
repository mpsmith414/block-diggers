# Block Diggers — Milestone 5: Camp — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The full loop. Hold B to ride a rope home, backpacks count into a shared ore bank, then spend it at camp on blueprints (buildings that assemble themselves) and shared upgrades. Everything saves.

**Architecture:** Pure `src/game/economy.js` (blueprints, upgrades, affordability, spending) and `src/save/save.js` (versioned load/save/migrate with storage fallbacks). `CampScene` is a cozy surface strip that reuses `stepPlayer` on a small camp grid with mining switched off. `src/scenes/ui/picker.js` is the shared blueprint/upgrade picker. `MineScene` gains the hold-B rope home.

**Spec:** main spec §1 "The loop", "Mining and upgrades", "Camp and blueprints"; §4 storage rows; §5 save and economy tests.

## Global Constraints

- Upgrade costs: Pickaxe iron = 10 iron + 5 coal, diamond = 5 diamond + 10 gold. Backpack 40 = 15 coal + 5 iron, 80 = 10 iron + 5 gold. Lantern 5 = 10 coal + 5 iron, 7 = 5 gold + 2 diamond.
- Blueprints: Flower Garden 15 coal; Cozy House 10 coal + 5 iron; Animal Pen 10 iron + 5 gold; Lookout Tower 20 iron + 5 gold; Minecart Loop 10 iron + 10 gold; Diamond Statue 5 diamond + 5 emerald.
- 6 building plots. A building assembles over ~5 s.
- Go home: either player holds B for 2 s → rope → both players pulled up with their backpacks.
- Save key `block-diggers-save`, version 2. Corrupt save → copied to `block-diggers-save-corrupt`, start fresh. Storage throws → in-memory.
- Picker controls: stick/D-pad left/right browse, A confirm, B close. Affordable options glow green.
- Commit messages end with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

### Task 1: economy

`BLUEPRINTS` (id, cost), `UPGRADES` (kind → per-level costs), `canAfford(bank, cost)`, `spend(bank, cost)` → new bank (throws if unaffordable), `nextUpgrade(state, kind)` → `{ level, cost } | null` when maxed, `buyUpgrade(state, kind)` → new state or `null`, `buildOnPlot(state, plot, id)` → new state or `null` (plot taken, unknown id, can't afford), `depositPacks(state, packs)` → new state with the ores added. State is immutable in and out.

Tests: every cost from the spec; affordability edge (exact amount); spending; upgrade level cap; buying twice; building on a taken plot fails; deposits add up.

### Task 2: save

`defaultState()`, `loadState(storage)` → `{ state, status: 'new'|'loaded'|'migrated'|'corrupt'|'unavailable' }`, `saveState(storage, state)` → bool, `migrate(raw)`. v1 shape `{ version: 1, bank, pick, pack, lantern, buildings: [id…] }` → v2 `{ version: 2, bank, upgrades: {pick, pack, lantern}, plots: [6], characters }`. Unknown fields are kept.

Tests: round trip; v1 migration; corrupt JSON → the corrupt copy is written and a fresh state returned; storage that throws → `unavailable` + default; save failures return false without throwing.

### Task 3: camp art + CampScene + picker

- Art: camp background (sunset sky, drifting clouds, hills, trees, flowers), campfire, workbench, plot stake, the six buildings (each drawn in a "build step" order so it can assemble), pig, sheep, minecart, rope.
- `CampScene`: 64-wide strip; the shaft on the left, the bench, the campfire, 6 plots. Players walk (no mining). Standing at the shaft and pressing down starts a trip. Standing at a plot or bench shows a floating A prompt; A opens the picker.
- On arrival from the mine: packs empty into the bank with ores flying from each player to the bank panel and the numbers counting up.
- Buildings: placed ones are drawn complete; a new one assembles row by row over 5 s with sparkles. The pen has wandering pigs and sheep, the house puffs chimney smoke, the minecart circles the camp.

### Task 4: rope home + scene flow + saving

- `MineScene`: hold B → a ring fills above the player; at 2 s a rope drops to each player and pulls them up with a whoosh; then `CampScene` starts with the packs.
- Flow: Boot → Camp. Camp → Mine (seed = now) → Camp.
- Save after each deposit, build and upgrade.
- **Verification:** browser: complete a loop (camp → mine → dig → hold B → camp), buy an upgrade, build 2 buildings, reload the page, and check they're still there. Screenshots.
