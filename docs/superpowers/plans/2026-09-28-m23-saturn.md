# M23: Saturn — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Saturn as planet 3, following the Mars recipe. Spec: `docs/superpowers/specs/2026-09-28-saturn-design.md`.

**Architecture:** Mostly data in the existing planet tables, plus a generator on `world/planetgen.js`, two art files, and three small new rules: the ice slide in `stepPlayer`, the Gloves' `digMul`, and `yetiDig`.

**Tech Stack:** Phaser 3.90, Vite, Vitest.

## Global Constraints

- Icons and sounds only: nothing a child needs to read.
- Gentle: ice only slides, it never hurts.
- Old saves load with nothing lost (v6 → v7).
- Block ids and tileset frames are only ever appended.
- The Earth, the Moon and Mars play exactly as before.
