# Block Diggers — Milestone 3: Co-op — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two players dig together on one screen. A shared camera zooms to fit both, a soft wall stops them drifting too far apart, and Y (or falling off-screen) floats a player to their partner in a bubble.

**Architecture:** Pure `src/game/camera.js` (framing maths, soft wall, off-screen test) and `src/game/bubble.js` (bubble movement). `MineScene` drives the Phaser camera from `frameCamera` each frame and applies the soft wall after each player step.

**Spec:** main spec §1 "Co-op camera", §1 "Solo play".

**How this plan is written:** each task fixes the interface and lists the behaviours its tests must pin down. Tests are written first.

## Global Constraints

- Zoom range 0.5×–1.5× (`CAMERA` in `tuning.js`), margin 40 px around the players.
- Soft wall: at minimum zoom, a player's *own* movement can't take them further from their partner than the view (at 0.5×) minus the margin on each side. Falling isn't blocked; it triggers the bubble instead.
- Bubble: invulnerable, passes through blocks, ~220 px/s, ends on the partner.
- Solo: camera follows the one player; soft wall and bubble are off.

### Task 1: camera maths

**Interface (`src/game/camera.js`):**
- `frameCamera(points, view = { w, h }, opts = CAMERA)` → `{ zoom, x, y }`: centre of the points' bounding box, and the zoom that fits it plus the margin, clamped to `[minZoom, maxZoom]`. One point → `maxZoom`.
- `wallLimits(view, opts = CAMERA)` → `{ dx, dy }`: the maximum allowed separation.
- `applySoftWall(prev, next, partner, limits)` → `{ x, y }`: for each axis, if `next` is further from the partner than the limit *and* further than `prev` was, keep `prev` on that axis.
- `isOffscreen(point, rect, pad = 8)` → bool.

**Tests must cover:** close points → max zoom; far points → smaller zoom; very far points → clamped at min zoom; centre is the midpoint; one point; the soft wall reverts only the offending axis; moving back toward the partner is always allowed; `isOffscreen` edges.

- [ ] Test, FAIL, implement, PASS, commit `feat(game): co-op camera framing, soft wall, off-screen test`.

### Task 2: bubble

**Interface (`src/game/bubble.js`):** `stepBubble(p, target, dt)` → `true` when it arrives. It moves the player's box towards `target` (a player box position) at `BUBBLE.speed`, ignoring blocks. On arrival it snaps to `target` and zeroes velocity.

**Tests must cover:** moves toward the target by speed × dt; arrives and snaps; never overshoots.

- [ ] Test, FAIL, implement, PASS, commit `feat(game): bubble to partner`.
