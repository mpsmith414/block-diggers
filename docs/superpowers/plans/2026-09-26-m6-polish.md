# Block Diggers — Milestone 6: Polish — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make it feel finished: cozy sound and music, a title screen with character select, a pause menu with mute, controller-disconnect handling, phone touch controls, and a rotate prompt.

**Architecture:**
- `src/audio/`: `synth.js` holds pure helpers (note → frequency, the song data). `audio.js` owns one `AudioContext` with master, sfx and music gains, plus mute and unlock. `sfx.js` has the named WebAudio voices. `music.js` is a look-ahead sequencer. `wire.js` subscribes the sounds to scene events.
- `TitleScene` (over a quiet camp backdrop): join with A, pick one of 4 characters, A to get ready.
- `PauseScene`: resume / mute / (in the mine) go home, controlled with the stick and A, icons only. It also shows the disconnect state.
- `src/input/touch.js`: DOM floating joystick and buttons that produce a normal `DeviceState` (`id: 'touch'`).
- CSS rotate prompt in `index.html`.

**Spec:** main spec §2 (sound, title/join, menus), §3 input (touch), §4 (disconnect, rotate).

## Global Constraints

- Audio starts only after the first user input. Mute persists in the save (`muted`).
- Characters: miner, fox, robot, dino. Two players can't pick the same one. The choice is saved.
- Pause: Start/Menu or View/Back, and the browser Back button. Icons only.
- Disconnect: pause; show a controller icon in that slot's colour; resume on reconnect.
- Touch: the left half of the screen is a floating joystick; the right half has jump (A) and a hold-home button (B). Touch is player 1.
- Commit messages end with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

### Task 1: audio
- `synth.js`: `noteFreq('A4') === 440`, `noteFreq('C5')`, sharps; `SONGS.camp` and `SONGS.mine` are `{ bpm, steps, tracks: [{ wave, gain, notes: [...] }] }` with every note parseable. **Tests:** frequencies; every song note parses; the tracks line up with the step count.
- `sfx.js` voices: dig (by hardness), ore (pitch rises with a streak), bonk, squash, chest, bubble, pop, whoosh, build, upgrade, deposit, tick, nope, jump, step.
- `music.js`: schedules 16th notes ~100 ms ahead; `play(name)` crossfades.
- `wire.js`: connects the scene events to sounds. Mine plays the `mine` song, camp plays `camp`.
- **Verify:** no console errors; the context unlocks on a key press; mute works.

### Task 2: title + character select
- Logo drawn in block letters (grass-topped dirt blocks) in `textures.js`.
- `TitleScene`: logo bobbing, sparkles, a big pulsing A. Each joined player gets a card: character (←/→ to change, taken ones skipped), A = ready (check). All ready → go to camp with `characters` saved.

### Task 3: pause + disconnect
- `PauseScene` launched over Mine or Camp (the scene underneath is paused): buttons ▶ resume, 🔊/🔇 mute, rope (go home, mine only). ←/→ select, A press, Start/B resume.
- Session reports a joined slot with no device → the scene opens pause in disconnect mode (controller icon, slot colour); it closes itself when the device is back.

### Task 4: touch + rotate + hints
- `touch.js`: `createTouch(target, doc)` → `{ read() → DeviceState, destroy }`. The joystick knob follows the finger (radius 50 px → axes −1..1). The A button sets `a`; the home button sets `b`. Tests with synthetic pointer events under jsdom.
- `devices.js`: include touch when `maxTouchPoints > 0`. Touch auto-joins on the first touch.
- Rotate prompt: a CSS overlay in portrait on narrow screens.
- Hint: when a backpack is full, a small "hold B" rope bubble floats over that player.
